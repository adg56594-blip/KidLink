Mode d'emploi — à lire pour ne pas se tromper

  1. Le pèlerinageCréé une seule fois (dates, lieu, prix par enfant). Il s'affiche en grand sur l'accueil.
  2. Le paiementUne famille ou une paroisse paie l'administrateur (espèces, Mobile Money). Il vous prévient sur WhatsApp.
  3. Le lienVous créez un lien pour exactement le nombre d'enfants payés, puis vous l'envoyez par WhatsApp.
  4. Les fichesLa famille remplit une fiche par enfant. Le lien se ferme tout seul quand le nombre est atteint.
  5. L'impressionVous téléchargez le PDF (20 bracelets par page A4) et l'envoyez à l'imprimeur.
  6. Après le pèlerinageVous videz les données (obligatoire pour la protection des enfants). Les gains restent visibles.

Nouveau paiement (créer un lien)

Quand ? Dès que l'administrateur confirme qu'une famille ou une paroisse a payé.

Comment ? Indiquez pour qui, qui a payé, le nombre d'enfants tapé deux fois, et l'argent reçu. Le site compare avec le prix normal et vous alerte en cas d'écart. Si vous avez fait une réduction, cochez la case prévue.

Attention : le lien n'est affiché qu'une seule fois. Envoyez-le tout de suite avec le bouton WhatsApp. Si vous l'avez perdu, ouvrez le lien et touchez « Nouveau lien » : l'ancien cessera de marcher.

Liens & inscrits

Chaque lien correspond à un paiement. Le cercle vert montre combien de fiches sont remplies sur le nombre payé.

« Désactiver » un lien : plus personne ne peut s'en servir (paiement annulé, lien envoyé à la mauvaise personne…).

« Désactiver » un bracelet (dans la liste des enfants) : à faire si un bracelet est perdu ou volé. Quiconque le scanne verra « Bracelet désactivé ».

{% endif %} {% if can.documents %}
Bracelets à imprimer (PDF)

Un PDF par paiement, 20 bracelets par page A4, avec le QR code, le nom de l'enfant et sa référence SK-0001.

Important pour l'imprimeur : imprimer à l'échelle 100 % (sans « ajuster à la page ») pour que les QR codes restent lisibles. Les bracelets désactivés ne sont pas imprimés.

Si une famille ajoute un enfant plus tard, retéléchargez le PDF : il contient toujours tous les enfants du lien.

{% endif %} {% if can.events or can.purge %}
Pèlerinages et effacement des données

Le pèlerinage à venir est affiché en grand sur l'accueil avec un compte à rebours. La date limite d'inscription ferme automatiquement tous les liens.

La durée de conservation (par défaut 30 jours après la fin) : passé ce délai, utilisez « Vider les données ». Si vous oubliez, le site les efface tout seul 15 jours plus tard. Les montants encaissés restent visibles sur la page « Les gains ».

{% endif %}
Ce que voit et fait l'administrateur

L'administrateur (le patron) voit les gains, crée et envoie des liens après paiement, peut remplir lui-même les fiches et voit les enfants inscrits. Il voit aussi la liste de l'équipe technique avec un bouton WhatsApp pour chacun (le numéro est celui indiqué dans « Mon compte » à l'inscription).

Il n'a jamais accès aux QR codes ni aux PDF : pour lui, ce sont les développeurs qui génèrent et préparent les bracelets. Pensez donc à télécharger les PDF des liens qu'il crée (page « Bracelets à imprimer »).

Le montant affiché est celui que vous saisissez en créant chaque lien : soyez exacts.

Comment marche le bracelet

Un passant scanne le QR code : la page affiche le nom de l'enfant, sa paroisse et un gros bouton « Appeler la famille ». Ça marche même sans internet (les informations sont dans le QR code).

Chaque QR code est signé : si quelqu'un modifie un numéro ou fabrique un faux, la page affiche « Bracelet FALSIFIÉ ». Le compteur « Faux bracelets » ci-dessus vous alerte.
